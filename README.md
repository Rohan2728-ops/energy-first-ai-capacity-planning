# Energy-First AI Capacity Planning

A synthetic decision model exploring how commercial AI demand can be translated into powered-compute placement, capacity protection, and future expansion decisions.

## Planning thesis

The model balances:

- current workload feasibility
- preservation of constrained capacity optionality
- energy-backed future expansion

Planning flow:

Commercial demand  
→ Workload requirements  
→ Energy availability  
→ Powered compute  
→ Future pipeline exposure  
→ PLACE / PROTECT / EXPAND

## Modeled recommendation

- PLACE: Customer Alpha → Site C
- PROTECT: Site A
- EXPAND: Site B

## Scope

All customer, site, energy, GPU, topology, commercial, probability, regional, and scoring assumptions are synthetic.

No Crusoe internal data, systems, or planning methods are represented.
